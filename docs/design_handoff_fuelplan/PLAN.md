# FuelPlan — plan zmian (wszystko zrobione w jednej turze)

- [x] 1. Plan = **napełnienia** przypisane do konkretnego pojemnika, nie luźne elementy.
- [x] 2. Pod wykresem **pas na każdy skonfigurowany pojemnik**; element żyje tylko w swoim pasie.
- [x] 3. **Brak nakładania** w pasie — pasek zatrzymuje się na sąsiedzie; dolewka tylko w wolnej luce.
- [x] 4. Osobny pas na jedzenie / dodatki — te mogą się nakładać.
- [x] 5. Licznik dolewek: per pojemnik (pas, karta, nawodnienie) i suma w nagłówku.
- [x] 6. Ustawienia pojemnika: co może wozić (woda / izo / żel) + **na ile porcji dzielić żel**.
- [x] 7. Mieszanka na **100 ml**: proporcja malto:fruktoza, cukry, sól, kwasek, stężenie żelu.
- [x] 8. Karta **„Skład pojemników"** — gramy na każde napełnienie osobno.
- [x] 9. Lista produktów: żel, banan, żelki, baton, **lody, ciasto, piwo zero, cola**.
- [x] 10. Oś wykresu: przełącznik **km ↔ godziny** (etykiety osi i zakresy elementów).
- [x] 11. Krzywa sprzężona z profilem: rośnie szybciej na podjazdach (+19%/%), wolniej na zjazdach.
